 [h3] 已实施的更改 [/h3]
 列表
  [*] [b]彩色编码图标[/b] - 直观的导航和漂亮的视觉效果
  [*] [b]No More Leader Portrait[/b] - 为您的漂亮旗帜提供更多空间！通过纹章导航到您的王朝/统治者！
  [*] [b]Static Flag Option[/b] - 喜欢 EU4 中的静态旗帜吗？现在可以选择了！有框架和无框架两种选择。
  [*] [b]Customizable Mapmode Bar[/b] - 自定义地图模式栏的高度/宽度。当前地图模式[/b]按钮的位置也有所改善。选择 "政治 "地图模式时不再显示（与 "地形 "相同）。
  [*] [b]彩色地图模式按钮[/b] - 根据类别为地图模式按钮添加了彩色色调，使使用更加方便！
  [*] [b]重新设计的地图模式类别列表[/b] - 重新设计了新版地图模式类别列表。
  [*] [b]Country Stats Panel[/b] - 可切换的国家统计面板 - 一目了然的国家信息！
  [*] [b]Visible Societal Values Equilibrium[/b] - 新增一个显示每个社会价值最大值的条形图。
  [*] [b]Toggleable Top Bar Stats[/b] - 根据个人喜好启用或禁用顶栏统计！动态战争统计自动隐藏/显示您的人力、水手和战争消耗！
  [*] [b]重新设计的事件查看器[/b] - 重新设计了简洁的事件查看器！
  [*] [b]Improved Building View[/b] - 在建造时查看地点的 [b]Building Limit[/b]、[b]RGO[/b] 和 [b]Control[/b] ！包括堡垒的 [b]Terrain Impact[/b] 地形影响[/b]！您可以点击地点的等级图标来升级/降级定居点！
  [*] [b]Improved Diplomacy Tooltip[/b] - 当鼠标悬停在一个国家上时，[b]您会看到它与当前选定国家的关系[/b]，而不是只看到您自己的关系。当鼠标悬停在附庸国时，我们还会显示更多相关信息。在战争期间，会列出一个国家当前调集的部队。
  [*] [b]改进的省份工具提示[/b] - 在省份工具提示的位置列表中添加了 RGO 和河流/海岸图标。
  [*] [b]改进的教皇公牛工具提示[/b] - 在投票按钮的工具提示中添加了教皇公牛效果，使用户无需深入查看 999 工具提示
  [*] [b]Zoom To Location[/b] - 平移到[b]国家首都[/b]、[b]军队所在地[/b]、[b]选定地点[/b]或[b]国际组织首都[/b]的位置！[b]（按 "Z "键即可！）[/b］
  [*] [b]位置视图地图模式[/b] - 将鼠标悬停在位置视图上的信息图标上，就会显示相关的地图模式。
  [*] [b]从原料查看器建造 RGO[/b] - 只需点击原料地图模式上的 RGO 地图图标，即可打开 RGO 建造菜单。
  [*] [b]综合地形影响[/b] - 在战斗中添加了显示综合地形影响修改器的标语
  [*] [b]Flashbang Be Gone[/b] - 移除每次进入游戏时的闪光弹介绍动画
  [*] [b]Activate Debug Mode[/b] - 使用 [b]Glorp UI Customization Menu[/b] 启用 [b]Debug Mode[/b]！
  [*] [b]Miscellaneous Improvements[/b] - Alert Banner 图标更大。Outliner 分类图标更大。
 [/list］
