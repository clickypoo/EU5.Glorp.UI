 [h3] カスタマイズ可能 [/h3]
 [list]
  [*] ゲーム内の [b]Glorp UI カスタマイズメニュー[/b] を使用して、自分好みの体験に [b]カスタマイズ[/b] しましょう！ 設定は [b]セーブデータごと[/b] に保存されます。
  [*] 他のModの実装の方がお好みですか？ ロードオーダーで [b]Glorp UI の後[/b] にそのModを配置するだけで、私たちの変更を上書きできます！
  [*] [b]Glorp UI[/b] は [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework[/url][/b] に完全に統合されています！ 統一された [b]Mod Menu[/b] からすべての設定を管理しましょう！
 [/list]

 [h3] 実装済みの変更点 [/h3]
 [list]
  [*] [b]カラーコード化されたアイコン[/b] - 直感的な操作と優れた視覚効果のために
  [*] [b]指導者の肖像画を廃止[/b] - 美しい国旗のためにより広いスペースを！ 紋章（Coat of Arms）をクリックすることで王朝や君主の画面に移動できます。
  [*] [b]静止旗オプション[/b] - EU4のような静止した旗がお好みですか？ オプションで選択可能になりました！ 枠あり・なしの選択も可能です。
  [*] [b]カスタマイズ可能なマップモードバー[/b] - マップモードバーの高さと幅をカスタマイズできます。[b]現在のマップモード[/b]ボタンも邪魔にならない位置に移動しました。「政治」マップモードは、選択時に（地形と同様に）表示されなくなりました。
  [*] [b]色付きのマップモードボタン[/b] - カテゴリに基づいてマップモードボタンに色を付け、使いやすさを大幅に向上させました！
  [*] [b]マップモードカテゴリリストの再設計[/b] - バニラのマップモードカテゴリリストのデザインを刷新しました。
  [*] [b]国統計パネル[/b] - 切り替え可能な統計パネルにより、国全体の情報を一目で確認できます！
  [*] [b]社会的価値観の均衡の可視化[/b] - 各社会的価値観の最大値を示す新しいバーを追加しました。
  [*] [b]切り替え可能なトップバーステータス[/b] - 好みに合わせてトップバーのステータスを有効・無効化できます！ 動的な戦争ステータス機能により、人的資源、水兵、戦時疲弊が自動的に表示・非表示になります。
  [*] [b]イベントビューアの再設計[/b] - シンプルすぎたイベントビューアを再設計しました！
  [*] [b]建物画面の改善[/b] - 建設時に場所の [b]建物制限[/b]、[b]生産資源（RGO）[/b]、[b]支配度[/b] を確認可能に！ 要塞の [b]地形補正[/b] も含まれます！ 場所のランクアイコンをクリックして、集落のアップグレードやダウングレードも可能です。
  [*] [b]投資回収率（ROI）[/b] - 建物を建設する際、その建物がコストを回収するまでにどれくらいの期間（y、m）がかかるかを示す、新しい投資回収率の統計を追加しました！
  [*] [b]プロヴィンスツールチップの改善[/b] - プロヴィンスツールチップの場所リストにRGOと河川・海岸アイコンを追加しました。
  [*] [b]教皇勅書ツールチップの改善[/b] - 投票ボタンのツールチップに教皇勅書の具体的な効果を追加し、ツールチップを何重にも開く手間を省きました。
  [*] [b]場所へのズーム[/b] - [b]国の首都[/b]、[b]軍の所在地[/b]、[b]選択した場所[/b]、または [b]国際機関の首都[/b] へ素早くパン（移動）できます！ [b]（「Z」キーを押すだけです！）[/b]
  [*] [b]場所画面のマップモード[/b] - 場所画面の情報アイコンにカーソルを合わせると、関連するマップモードが表示されます。
  [*] [b]原材料ビューアからのRGO建設[/b] - 原材料マップモード上のRGOマップアイコンをクリックするだけで、RGO建設メニューを開けます。
  [*] [b]地形補正の合計[/b] - 戦闘中に適用されている地形補正の合計値を表示するバナーを追加しました。
  [*] [b]さらばフラッシュバン[/b] - ゲーム開始時に毎回流れる眩しいイントロアニメーションを削除しました。
  [*] [b]デバッグモードの有効化[/b] - [b]Glorp UI カスタマイズメニュー[/b] から [b]デバッグモード[/b] を有効にできます！
  [*] [b]その他の改善[/b] - 警告バナーのアイコンとアウトライナーのカテゴリボタンを大きくしました。
  [*] [b]...その他多数！[/b]
 [/list]
